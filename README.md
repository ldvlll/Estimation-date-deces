# Estimation-date-deces
Programme Python permettant d’estimer la date d’un décès à partir de paramètres environnementaux et physiques ( créer à partir du nomogramme post-morthem et la loi de Newton du refroidissement), projet personnel ( extension de mon sujet Grand Oral de mathématiques )
Estimation comportant certaines limites notamment si la température corporelle est inférieur ou égale à la température du milieu, ou si la temperature du milieu est égale à la température moyenne d'un corps.
